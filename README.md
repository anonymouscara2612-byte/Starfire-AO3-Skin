# Starfire-AO3-Skin
How To Add Skin:

1. Copy the code

2. Go to Ao3, your username -> my dashboard -> skins -> create site skin (near the top right).

3. Give it a title, it has to be unique (I like to smash my keyboard at the end) then paste the code you copied in the CSS box.

4. Scroll to the end, hit submit.

5. Once it's created, just click "Use" to apply the skin.
